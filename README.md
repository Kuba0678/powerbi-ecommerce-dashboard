# E-commerce Sales & Operations - Power BI Dashboard 

A comprehensive Power BI dashboard designed to track Key Performance Indicators (KPIs) for the e-commerce industry. I built this project independently from scratch, focusing on delivering immediate business value and actionable insights.

## Project Overview

* **Business Analytics:** Analyzed sales metrics including net profit, margins, average order value, and return reasons to support data-driven decision making.
  
* **Data Modeling:** Built a standard star schema model using core e-commerce tables (Customers, Product Catalog, Order Details).
  
* **Advanced DAX & Organization:** Wrote custom DAX measures for financial and operational calculations. Maintained a clean development environment by grouping all measures into numbered thematic folders (e.g., Revenues & Costs, Deliveries & Operations).
  
* **UI/UX Design:** Designed a clean, corporate layout split into two distinct pages: Financial Overview and Operations Analysis for intuitive reporting.

## How to view the project
1. Download the `.zip` file from this repository and extract it.
2. Open the extracted `.pbix` file using Microsoft Power BI Desktop.
3. Interact with the filters and slicers to explore the data dynamically.
